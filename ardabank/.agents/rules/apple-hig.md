# Apple Human Interface Guidelines (HIG) Rules

1. **SF Pro & System Typography**: Use SF Pro typography family (`-apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text", system-ui`), tight letter spacing (`tracking-tight`), and crisp text hierarchy.
2. **Liquid Glassmorphism**: Apply Apple frosted glass (`backdrop-filter: blur(30px) saturate(190%)`), translucent dark backdrops (`rgba(28, 28, 30, 0.65)`), and specular inner highlights (`box-shadow: inset 0 1px 0 0 rgba(255, 255, 255, 0.12)`).
3. **Continuous Squircle Curves**: Enforce Apple continuous squircle corner radii (`rounded-[24px]`, `rounded-[28px]`, `rounded-[32px]`) with concentric padding.
4. **Apple iOS Color System**: Utilize iOS system tint colors—Apple Green (`#30d158`), Apple Cyan (`#64d2ff`), Apple Red (`#ff453a`), Apple Purple (`#bf5af2`), Apple Amber (`#ffd60a`), and Pitch Dark Canvas (`#000000`).
5. **iOS Floating Dock & Controls**: Implement iOS Segmented Controls, floating action docks (`apple-dock`), bottom sheet modals with grabber bars (`w-10 h-1 bg-white/20 rounded-full`), and tactile press feedback (`apple-press`).
